# Timezone Board

A personal glance website that shows five fixed world time zones. Built as a small demonstration project for a colleague.

## Language

**Timezone Board**:
The single-page website that shows five Zones at a glance.
_Avoid_: dashboard, world clock app, multi-timezone tool

**Zone**:
One of the five fixed places on the Timezone Board, identified by an IANA timezone and shown with a human city label.
_Avoid_: clock, timezone entry, location slot

**Glance view**:
The always-on first (and only) screen of the Timezone Board: the composition a visitor reads in one look.
_Avoid_: home page, clock grid, widget panel
